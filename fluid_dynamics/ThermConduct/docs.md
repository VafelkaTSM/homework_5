### 1.3 Кнопка остановки расчёта
- `ThermConductSim.Mesh`: добавлены `volatile bool _stopRequested`, `bool WasStopped`, метод `StopCalc()`; в цикле `StartCalc` перед каждой итерацией проверяется флаг → расчёт выходит, сохраняя уже посчитанные температуры, `Iteration` и `Time`. Повторный `StartCalc` сбрасывает флаг, т.е. расчёт можно перезапускать.
- UI: кнопка «Остановить» между «Старт расчёта» и «Сброс»; активируется только во время расчёта (`RequestStop()`), после остановки строка состояния пишет «Расчёт остановлен пользователем: N итераций, t = … с, a = … м^2/с.».
- Потокобезопасность: флаг `volatile`, сам расчёт — в фоновом потоке (`Task.Run`), UI-обновления — через `Dispatcher.UIThread.Post`.

### 1.4 Поле «итераций до обновления интерфейса»
- Новое поле `Обновлять каждые: [N] итераций` (по умолчанию `1`), значение передаётся в `Mesh.StartCalc(..., updatePeriod)` вместо прежней автоматической формулы `iterations/200`.
- Валидация: целое ≥ 1, иначе сообщение об ошибке и расчёт не стартует. Значение дублируется в строке состояния.

### 1.5 Температуры без «...»

  - `FormatSigma(value)` → `67600`, `0,557` и т.п. без обрезки.
